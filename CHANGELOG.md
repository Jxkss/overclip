# Changelog

All notable changes are listed here. Format based on [Keep a Changelog](https://keepachangelog.com).

## [0.1.0] — first public release

### Added
- Full-screen gallery overlay (<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd>) and a slim side panel
  (<kbd>Ctrl</kbd>+<kbd>P</kbd>); both shortcuts are customisable.
- Setup wizard after install: detects recorder folders (Game Bar, ReLive, ShadowPlay, OBS, Medal,
  Outplayed, ShareX, Windows screenshots), shortcuts, look and behaviour.
- Settings window: accent colour, dark / OLED-black themes, interface size, background dimming,
  animations, gallery size, side panel position and width, thumbnail size, and more. Changes apply
  instantly.
- Game sidebar with cover art, day grouping, search, favourites, multiple clip folders/drives.
- Hover-to-play, preview player with ← → navigation, multi-select, right-click menu.
- <kbd>Ctrl</kbd>+<kbd>C</kbd> copies the file itself (paste straight into Discord).
- Recycle Bin deletes, rename, show in Explorer.
- Per-app volume mixer.
- Recorder control: Save replay, Record and Screenshot buttons in the overlay, driving AMD
  Software, Xbox Game Bar, OBS Studio, NVIDIA App or Medal.
- Recording settings inside Overclip for AMD Software (incl. stereo audio to avoid 7.1 clips
  Windows can't play), Xbox Game Bar and OBS Studio.
- Screenshots saved next to clips (e.g. by AMD Software) show up in the Screenshots tab.
- Fast thumbnails via the Windows thumbnail cache, background scanning, single-instance app.
